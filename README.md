# SMB_PKT_CONFIG
## Overview
Small business design and configuration of a network using cisco packet tracer. Connects office PCs and a printer through a router and switch.

## Network Design
- 1 router
- 1 switch
- 4 PCs
- 1 Network printer\
\see topology.png

## IP Addressing
Router : '192.168.10.1'\
Printer : '192.168.10.10'\
Office PCs: DHCP: '192.168.100-199'

## Configuration
- Configred IP addressing and DHCP
- Set default gateway
- Connected end devices through the switch 

## Testing 
- Verified that PCs received valid IP addresses
- Tested connectivity to the default gateway
- Tested connectivity between office devices
- confirmed printer connectivity from devices

## Skills Demonstrated
- IPv4 addressing and subnet mask
- DHCP and default gateways
- Basic switching and routing
- Ping based connectivity testing
